# Telekom CompanyFlex Cloud PBX

Weiterleitung auf die Dr.wait-Rufnummer (Weg A). Für die Cloud-Telefonanlage der Telekom (CompanyFlex Cloud PBX, Cloud PBX 2.0, früher DeutschlandLAN Cloud PBX).

Sie brauchen nur die Rufnummer des Telefonassistenten von Dr.wait. SIP-Zugangsdaten sind nicht nötig.

## Einrichtung

1. Im Verwaltungsportal der Cloud PBX die Rufnummer bzw. Gruppe öffnen, auf der Patientenanrufe eingehen.
2. Unter **Anrufweiterleitung** eine Weiterleitung auf eine externe Rufnummer anlegen.
3. Ziel: Rufnummer des Telefonassistenten.
4. Bedingung wählen: sofort, nach einer Wartezeit oder bei besetzt.

## Rufnummer des Anrufers

Die Telekom bietet für die Cloud PBX die Option „Clip no screening“ an. Kommt beim Test nur die Praxisnummer an, fragen Sie Ihren Telekom-Ansprechpartner nach dieser Option für weitergeleitete Anrufe.

## Ein- und ausschalten

Die Weiterleitung deaktivieren bzw. wieder aktivieren.

## Test

Von einem Mobiltelefon die Praxisnummer anrufen, bis der Assistent übernimmt. Im Posteingang muss die Nummer des Mobiltelefons erscheinen. Steht dort die Praxisnummer, fragen Sie Ihren Anbieter nach „CLIP no screening“ für Weiterleitungen.
